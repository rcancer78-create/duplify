# Duplify: руководство и устройство проекта

**Duplify** — настольное приложение на C# / .NET 8 (WPF) с интерфейсом в тёмном стиле на русском языке, предназначенное для быстрого поиска одинаковых файлов, просмотра групп дубликатов и их безопасного разрешения (удаление в Корзину, перемещение в отдельную папку или полуавтоматический массовый разбор).

---

[← К README](../README.md). Команды выполняются из корня репозитория.

## 🚀 Сборка и запуск

### Требования
* Операционная система: **Windows 10 / 11**
* Установленный **.NET 8 SDK** (версия 8.0+)

### Сборка проекта
В корневой папке проекта выполните команду:
```bash
dotnet build Duplify.sln
```
Для сборки включён `<TreatWarningsAsErrors>true</TreatWarningsAsErrors>`; результат текущей версии проверяется отдельным запуском сборки.

### Запуск приложения
Запустите приложение командой:
```bash
dotnet run --project Duplify.csproj
```

### Запуск тестов

#### 1. Модульные тесты xUnit:
```bash
dotnet test Duplify.sln
```

#### 2. Встроенный автономный самотест (headless):
```bash
dotnet run --project Duplify.csproj -- --test
```
Проверяет изолированно во временной директории: сканирование, SHA-256 хеширование, hardlink-идентификацию NTFS, защиту от удаления последней копии, ротацию журнала действий, разрешение конфликтов имён, сохранение настроек и массовый планировщик.

### Публикация Release (framework-dependent, win-x64)
```bash
dotnet publish Duplify.csproj -c Release -r win-x64 --self-contained false
```
Исполняемый файл:
```text
bin\Release\net8.0-windows\win-x64\publish\Duplify.exe
```

## 📂 Данные приложения

Все пользовательские данные хранятся локально в `%AppData%\Duplify\`:

| Путь | Назначение |
| --- | --- |
| `%AppData%\Duplify\settings.json` | Параметры фильтрации и папки последнего сканирования (атомарная запись, сохранение `.bad` при сбое). |
| `%AppData%\Duplify\journal.jsonl` | Append-only журнал действий в формате JSONL с ротацией по размеру (поддерживает `FileShare.ReadWrite`). |
| `%AppData%\Duplify\logs\` | Журналы аварийных исключений (`CrashLogger`). |

Пункты верхнего меню позволяют быстро открыть журнал действий, папку логов или окно «О программе».

## ✨ Безопасность и архитектурные решения

* **Двухфазный поиск**:
  1. Первичная группировка по размеру. Файлы уникального размера никогда не читаются и не хешируются.
  2. Вычисление SHA-256 контрольной суммы только при совпадении размеров. Игнорируются пустые файлы (0 байт).
* **Скан директорий в один проход (`FileSystemEnumerable`)**:
  Размер, атрибуты и дата изменения получаются напрямую из дескриптора файловой системы без лишних системных вызовов `FileInfo` и `File.GetAttributes`.
* **Защита от зацикливания и утечки корней (`SafetyGuards`)**:
  * Сканер проверяет `IsReparsePoint` для исключения junction/symlink при обходе. Это не блокирует изменения дерева другими процессами.
  * Fail-closed защита от опасных корней сканирования (`IsDangerousScanRoot` блокирует корень диска, пользовательский профиль и некорректные пути).
  * Предупреждение при перемещении файлов внутрь уже просканированного дерева.
* **Сохраняемая копия и повторная проверка (`DuplicateActionGuard`)**:
  Перед удалением или перемещением должны остаться неотмеченные копии. Для выбранного файла и доступной физически отдельной сохраняемой копии заново проверяются размер и SHA-256, затем идентичность открытых файлов и текущих путей. Сохраняемая копия удерживается открытой без разрешения записи/удаления до завершения действия. Изменившийся, занятый или недоступный выбранный файл, а также отсутствие подтверждённой сохраняемой копии приводят к пропуску действия с записью причины в отчёт и журнал.
  Если для удаления отмечены все файлы хотя бы одной группы, операция не начинается: снимите отметку с сохраняемой копии. Подтверждения, разрешающего удалить последнюю копию, нет. Во время удаления и перемещения новое сканирование недоступно.
  Это не атомарная транзакция: внешнее переименование или подмена пути после последней проверки всё ещё возможны, поскольку системные операции выполняются по пути. Работайте с резервными копиями и избегайте одновременно изменяемых каталогов.
* **Корзина по умолчанию и подтверждение постоянного удаления**:
  Удаление идёт в Корзину (`Microsoft.VisualBasic.FileIO`). Если Корзина недоступна, приложение запрашивает явное подтверждение на постоянное удаление. После этого диалога обе копии проверяются и блокируются заново; согласие не позволяет обойти проверку сохраняемой копии.
* **Потокобезопасное превью изображений (`ImageThumbnailService`)**:
  Декодирование миниатюр происходит через `FileStream` с ограничением `DecodePixelWidth` без загрузки всего файла в память, а кэш защищён LRU-ограничением.
* **Массовый разбор (`BulkSelectionPlanner` / `BulkResolveDialog`)**:
  Правила приоритета (предпочтительная папка, короткий путь, чистое имя без `(1)`, дата). Неоднозначные группы не выбираются наугад, а пропускаются для ручной проверки кнопкой «Показать следующую неоднозначную».
